# AI Projects

## Voice-First AI Portfolio

This is the current portfolio project.

- Voice-first AI portfolio designed for recruiter interaction.
- Next.js and TypeScript frontend.
- Python and FastAPI backend.
- Browser-based Speech-to-Text and Text-to-Speech.
- Ollama used for local LLM development.
- Retrieval-Augmented Generation using portfolio Markdown content.
- Embeddings generated with Ollama and `nomic-embed-text`.
- In-memory cosine-similarity retrieval using NumPy.
- Controlled AI navigation that can navigate recruiters to relevant
  portfolio sections.
- AI responses are grounded in verified portfolio information.
- Controlled actions are used instead of arbitrary browser, JavaScript,
  shell, or DOM execution.
- Architecture is designed so the development LLM/provider can be changed
  later.
- Project is being developed incrementally with testing at each phase.

## Voice-Based Email System for Visually Impaired Users

- Built a Python-based voice-controlled email application enabling
  visually impaired users to compose, send, read, and manage emails using
  Speech-to-Text and Text-to-Speech technologies.
- Integrated speech recognition and voice synthesis to deliver a
  hands-free, accessibility-focused user experience.
- Implemented voice-driven email workflows including composing messages,
  reading inbox content aloud, and executing email actions through spoken
  commands.
- Improved speech recognition reliability through input validation and
  error handling while following accessibility-focused design principles.
